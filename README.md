# 5G-MAG Roadmaps

Each issue in this repository is one entry in the roadmap of a 5G-MAG project. The entries appear in the roadmap block of the project pages of the 5G-MAG website.

The board [5G-MAG Roadmaps](https://github.com/orgs/5G-MAG/projects/76) decides what is shown:

- The label `project:<slug>` says which project an entry belongs to.
- The Status column is the column on the page: Brought to Study, On-Going or Outcomes.
- The order of the cards in a column is the order on the page.
- Only entries on the board with **Show on page** set to Yes, and still open, appear.

Everything in this repository and on the board is public. Editing is limited to 5G-MAG officials.
